# Profiles

Профиль выбирается строго в два этапа:

1. точное имя пакета;
2. точная версия приложения – `versionCode` и `versionName`.

Профили разных пакетов никогда не объединяются. В частности, `com.heytap.themestore` – CN Theme Store для OPPO, а `com.oplus.themestore` – отдельный Theme Store для OnePlus. Совпадение названия приложения не является основанием для загрузки чужого словаря.

Если точного профиля нет, Cobalt не применяет перевод и не использует ближайшую версию автоматически.
