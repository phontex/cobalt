# Процесс репозитория

- Исходники и схемы находятся в ветке `main`.
- Релизы приложения и Cobalt Platform публикуются отдельно.
- Словари и профили обновляются независимо от APK.
- Перед применением проверяются package name, versionCode, подпись и SHA-256.
- Автоматическая установка и загрузка файлов без подтверждения пользователя не используются.
