# Cobalt Platform

Привилегированный исполнитель Cobalt. Не содержит APK, не скачивает файлы и не решает,
что менять: получает данные от приложения и выполняет только те операции, которые
реализованы в этой версии модуля.

Правило безопасности: **никакого исполнения команд с сервера**. Сервер отдаёт данные,
приложение вызывает известную команду, платформа проверяет её аргументы по своим спискам.
Новая операция — новая версия модуля.

Подробности — `docs/platform-contract.md`.
