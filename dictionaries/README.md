# Dictionaries — часть Cobalt App

Перевод строк, которые приложение получает в рантайме: литералы из dex и текст с сервера.
LSPosed-часть подменяет их в процессе приложения.

```
dictionaries/<package>/<version>/<language>.json
```

Формат: `{"schema_version":1,"package":"…","version_name":"…","language":"ru","entries":{"оригинал":"перевод"}}`

- ключ — точная строка, как её видит пользователь;
- добавили строку — она подхватится после следующей проверки обновлений;
- пустой файл (`"entries": {}`) — нормальное состояние: перевод ещё не собран.

Подробнее — `TRANSLATIONS.md` в корне.
