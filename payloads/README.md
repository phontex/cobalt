# Payloads

Файлы, которые применяет **Cobalt Platform**, а не приложение.

```
payloads/<package>/<version_name>/resources.arsc
```

`resources.arsc` — таблица ресурсов с русскими строками для конкретной версии приложения.
Платформа монтирует собранный из него APK поверх установленного, поэтому:

- payload относится к одной версии и не переносится на другую;
- файл проверяется по `sha256` из `manifests/catalog.json` до применения;
- в каталоге слой `apk_resources` имеет `served_by: "platform"` и `available: false`,
  пока файла здесь нет — приложение показывает «Пока не собраны» и ничего не ломает.

## Чем это отличается от словаря

| | Словарь (`dictionaries/`) | Payload (`payloads/`) |
|---|---|---|
| Кто применяет | Cobalt App (LSPosed, рантайм) | Cobalt Platform (подмена APK) |
| Что покрывает | строки, видимые в рантайме | ресурсы, которые нельзя перехватить |
| Привязка к версии | нет, работает на любой | жёсткая, по `version_name` |
| Размер | сотни КБ | мегабайты |

## Как собрать payload

Сборка выполняется вне телефона (или в Termux через apktool):

1. взять `base.apk` нужной версии;
2. разобрать, добавить `res/values-ru/strings.xml` с переводами по именам ресурсов;
3. собрать, взять из результата `resources.arsc`;
4. вложить этот `resources.arsc` в **оригинальный** `base.apk` вместо старого
   (dex, библиотеки и остальные записи не трогаются);
5. записать в каталог `sha256` и `bytes`, поставить `available: true`.

Имена ресурсов в Theme Store обфусцированы (`a`, `b`, `c`), поэтому соответствие
«имя → строка» берётся из каталогов локализации, которые лежат в `dictionaries/`.
