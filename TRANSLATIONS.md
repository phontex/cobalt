# Cobalt translations

Переводы хранятся как редактируемые исходники. APK Cobalt и Cobalt Platform не нужно менять
после изменения текста: GitHub Actions собирает агрегаты, обновляет каталог и создаёт changelog.

## Структура

```text
translations/<package>/app/
  legacy.json    ранее проверенные пары; не удалять без сравнения
  dex.json       статические строки из classes.dex
  assets.json    строки из assets
  server.json    строки, которые приходят от сервера; сюда добавляются новые строки
  ru.json        сгенерированный файл для Cobalt App

translations/<package>/platform/
  resources.json      редактируемые пары для resources.arsc
  source-records.json полный исходный resource_text из ZIP
  conflicts.json      одинаковые исходные строки с разными кандидатами
  ru.json             сгенерированный файл для Cobalt Platform

changes/
  index.json           список выпусков переводов
  YYYY-MM-DD-*.md     подробный журнал: добавлено, изменено, удалено
```

## Что редактировать

Редактируются только `app/*.json`, кроме `ru.json`, и `platform/resources.json`.
Формат исходного файла:

```json
{
  "schema_version": 1,
  "package": "com.heytap.themestore",
  "layer": "app",
  "section": "server",
  "language": "ru",
  "entries": {
    "限时特惠": "Выгодное предложение"
  }
}
```

Ключ — исходная строка, значение — русский текст. Пустое значение — заготовка и не
попадает в активный словарь. Для составных серверных строк Cobalt применяет нормализацию
пробелов, регистра и `%d`/`%1$s`-плейсхолдеров, а затем безопасно заменяет опубликованные
фрагменты, начиная с самого длинного.

## Как появляется обновление

1. Изменяется исходный JSON в GitHub.
2. Workflow `translations.yml` проверяет JSON и запускает `tools/update_translations.py`.
3. Скрипт заново строит `ru.json`, считает SHA-256 и количество активных записей.
4. В `changes/` создаётся журнал с разделами и каждой добавленной, изменённой или удалённой парой.
5. `manifests/catalog.json` получает новый `content_id`, размер, хэш, summary и ссылку на журнал.
6. Cobalt App при проверке каталога скачивает новый слой, проверяет SHA-256 и устанавливает его.

## Две ответственности

- `app` — Cobalt App + LSPosed: DEX, assets и серверный текст.
- `platform` — Cobalt App строит APK с новым `resources.arsc`, Cobalt Platform выполняет
  только привилегированное монтирование в namespace init.

Платформенный JSON содержит все 3400 записей `resource_text` из присланного каталога и
6606 уникальных переведённых пар. В установленной версии применяются только совпавшие
строки; поэтому один и тот же редактируемый источник работает для новых версий без жёсткой
привязки к номеру версии. Версия остаётся предупреждением совместимости.

## Безопасность

Каталог поставляет только данные. Cobalt Platform не выполняет команды из GitHub. Все
операции платформы заранее зашиты в модуль и проверяются whitelist-правилами.
