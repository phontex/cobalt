# Переводы Cobalt

Перевод разделён на **две части**, потому что за них отвечают разные компоненты.
Обе лежат в этом репозитории, обе обновляются **без выпуска новой версии** приложения или модуля.

```
dictionaries/<package>/<version>/<language>.json     ← часть приложения
payloads/<package>/<version>/resources.arsc          ← часть платформы
```

## Какая часть за что отвечает

| Часть | Кто применяет | Что внутри | Когда работает |
|---|---|---|---|
| `dictionaries/` | Cobalt App + LSPosed | строки, которые приложение получает **в рантайме**: литералы из dex, текст с сервера | сразу, без перезагрузки |
| `payloads/` | Cobalt Platform | `resources.arsc` — таблица ресурсов APK | после применения, приложение перезапускается один раз |

Почему нельзя одной частью: строки `Home`, `Category`, `Me` вшиты в dex — их видно
только в момент отрисовки; а `推荐`, `No Data` лежат в ресурсах — их можно заменить
файлом. Проверено разбором APK 17.23.0beta1: 619 142 строки в dex, из них
`Home`, `Category`, `Me`, `VIP` — только в dex, а `推荐` и `No Data` — только в `resources.arsc`.

## Как менять перевод вручную

### Часть приложения (dex и сервер)

Файл: `dictionaries/<package>/<version>/<language>.json`

```json
{
  "schema_version": 1,
  "package": "com.heytap.themestore",
  "version_name": "17.22.1",
  "language": "ru",
  "entries": {
    "Home": "Главная",
    "Category": "Категория",
    "No Data": "Нет данных"
  }
}
```

- ключ — **точная строка, как её показывает приложение**;
- значение — перевод;
- добавили строку в `entries` → она начнёт переводиться после следующей проверки обновлений в приложении;
- ключи с `\u0001cobalt_` зарезервированы.

### Часть платформы (ресурсы APK)

Файл: `payloads/<package>/<version>/resources.arsc` + запись в `manifests/catalog.json`.

Порядок:

1. взять `resources.arsc` из APK нужной версии;
2. заменить строки на перевод (инструмент сборки — отдельная задача);
3. положить файл в `payloads/<package>/<version>/`;
4. в `manifests/catalog.json` у слоя `apk_resources` указать:
   `payload.path`, `payload.sha256`, `payload.bytes`, `payload.available: true`;
5. `verified_version` — версия, из которой собран файл.

## Правила именования

- `<package>` — точное имя пакета (`com.heytap.themestore`);
- `<version>` — `version_name` приложения (`17.23.0beta1`), не код;
- `<language>` — код языка (`ru`).

## Как приложение находит перевод

1. Скачивает `manifests/catalog.json`.
2. Сверяет установленные пакеты **локально**, ничего не отправляя.
3. Для части приложения: скачивает `dictionaries/…`, проверяет SHA-256, кладёт к себе,
   отдаёт в процесс приложения через провайдер.
4. Для части платформы: скачивает `payloads/…`, собирает APK на устройстве,
   передаёт платформе, платформа монтирует в namespace init.

## Версия приложения

Привязки нет. Если версия не совпадает с `verified_versions` — предупреждение, а не отказ.
Для `payloads/` версия важна: файл собран из конкретного APK.

## Заготовки

Пустые файлы-заготовки лежат рядом с переводами: `README.md` в каждой папке объясняет,
что туда класть. Пока файла нет, приложение показывает «Перевод не собран» и ничего не ломает.
